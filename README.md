# Nashy Trellis

Official website project for Nashy Trellis — custom aluminium security solutions in Durban, KZN.

## Current build

The first responsive production prototype includes:

- Premium Nashy Trellis visual system
- Desktop and mobile layouts
- Trellis gates, window security, burglar bars, monkey-proof gates and balustrades
- 10-year guarantee and commercial trust propositions
- Colour/finish selector
- Project-gallery framework
- WhatsApp-first quotation journey
- Sticky mobile WhatsApp, call and quote controls

## Preview

This repository is structured as a static site and can be published directly with GitHub Pages from the `main` branch and repository root.

## Production work remaining

Client installation photographs will replace the temporary architectural product-pattern placeholders as the gallery is finalised. Final legal wording for guarantee/price-promise claims, vector brand masters, product pages, structured data, analytics and final QA will be completed before client launch.
